冲刺背诵手册 · 静态网站部署说明
================================

这个文件夹就是一个完整的静态网站：
  index.html        首页（三张卡片）
  up-pages.html     上册原版页（240 页）
  down-pages.html   下册原版页（89 页）
  book-all.html     文字版合集（可搜索）
  pages/            上册页面图片
  pages-down/       下册页面图片
  thumbs/           上册缩略图
  thumbs-down/      下册缩略图

整个文件夹约 74 MB，共 662 个文件。不要改动文件名和目录结构。

------------------------------------------------
方式 A：Netlify Drop（最快，拖拽即可）
------------------------------------------------
1. 电脑浏览器打开 https://app.netlify.com/drop
2. 把整个 site 文件夹拖进页面
3. 几秒后得到一个网址，形如 https://xxxx-xxxx.netlify.app
4. 手机/iPad 直接打开这个网址即可（不需要电脑开机）
5. 免费账号可长期保留、可改自定义域名

注意：拖拽时请拖"文件夹"，不要只拖 html 文件。

------------------------------------------------
方式 B：Cloudflare Pages（免费、稳定、国内可访问）
------------------------------------------------
1. 注册 https://dash.cloudflare.com （邮箱即可）
2. 左侧 Workers & Pages → Create → Pages → Upload assets
3. 把 site 文件夹里的全部内容拖进去（或上传 zip）
4. 发布后得到 https://项目名.pages.dev
5. 单个文件限制 25MB —— 本网站最大的 html 只有 1.5MB，
   图片都是 200KB 左右，完全没问题

------------------------------------------------
方式 C：GitHub Pages（有 GitHub 账号的话）
------------------------------------------------
1. 新建仓库，把 site 里的文件全部上传（保留目录）
2. Settings → Pages → Source 选 main 分支 → / (root)
3. 得到 https://用户名.github.io/仓库名/
   国内访问可能偏慢

------------------------------------------------
方式 D：国内对象存储（阿里云 OSS / 腾讯云 COS）
------------------------------------------------
1. 开通 OSS/COS，创建 Bucket，权限设为"公有读"
2. 上传 site 里全部文件
3. 开启"静态网站托管"，首页默认 index.html
4. 用 Bucket 的默认域名访问
   （绑定自己的域名需要 ICP 备案）

------------------------------------------------
常见问题
------------------------------------------------
Q: 手机上打开会不会很慢？
A: 首页很轻；原版页是逐页懒加载（一页约 150-200KB），滚动很顺。

Q: 想加到手机桌面？
A: iPhone 用 Safari 打开网址 → 分享 → 添加到主屏幕。

Q: 以后改了内容怎么办？
A: 重新上传替换即可（Netlify 可再次拖拽覆盖）。

Q: 不想公开、只想自己看？
A: Netlify/Cloudflare 都可以设置密码保护（Password protection，需在站点设置里开）。
